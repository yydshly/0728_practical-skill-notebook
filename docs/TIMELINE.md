# 时间轴地图

滚动长度为 `4400px`。页面使用局部进度 `p = clamp((scrollY - sectionTop) / travel)`，所以无论从哪个位置进入或反向滚动，画面都能由同一组函数重建。

| 进度 / 区间 | 画面与内容 | 主要变量 |
| --- | --- | --- |
| `0` | 完整灯塔开场、标题与引导可见 | `--intro-opacity: 1`、前景未打开 |
| `0.03–0.18` | 开场文案淡出，世界开始轻微推进 | `--intro-opacity`、`--world-scale` |
| `0.15–0.25` | 两侧礁石向外打开 | `--fg-left-x`、`--fg-right-x` |
| `0.22–0.44` | 守灯人的故事面板进入、停留、退出；主段标注为 `0.25–0.44` | `--story-a-opacity`、`--focus` |
| `0.44–0.48` | 纯景观呼吸段 | 叙事透明度归零 |
| `0.48–0.74` | 雾中信号面板进入、停留、退出；主段标注为 `0.48–0.69` | `--story-b-opacity`、`--focus` |
| `0.69–0.76` | 世界复焦 | `--focus → 0` |
| `0.75–0.96` | 航线档案进入 | `--archive-progress` |
| `0.91–1` | 档案控制器完全显现 | `--controls-opacity` |
| `1` | 最终路线状态，面板可点击、可拖拽、可键盘操作 | `archive-active` 类、`--archive-progress: 1` |

页头跳转点为：灯塔 `0`、信号 `0.5`、航线 `1`。

## 图层规则

舞台将进度写入 CSS 自定义属性。天空以轻微反向指针视差移动，中景与主体以正向视差移动；两侧近景使用更强的开场位移。移动指针被禁用时，所有指针目标回到零。

当档案进度超过最小可见阈值，舞台根节点会增加 `archive-active`，从而只在档案出现后开放指针事件；反向滚动时该状态同步撤销。

## 窄屏与减少动态效果

- 宽度不大于 `820px`：全部图层使用 `object-position: 76% center`，保证竖屏仍能看到灯塔。
- 宽度不大于 `760px`：叙事面板变为窄屏宽度，档案改为单列，近景位移降至 45%。
- 粗指针和减少动态模式：关闭指针视差。
- `prefers-reduced-motion: reduce`：舞台改为普通文档流，开场、两段叙事与档案都静态、顺序可读；动画式滚动跳转改为即时跳转。
