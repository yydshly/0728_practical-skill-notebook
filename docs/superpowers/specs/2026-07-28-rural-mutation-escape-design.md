# 乡村异变逃生序章：设计规格

## 目标

构建一个可在桌面浏览器运行的原创第三人称叙事逃生纵切片。玩家在黄昏的乡村发现居民躲藏和村民异变，通过探索、躲避和一次追逐抵达南侧村口逃离。

## 范围

- 5–8 分钟单章体验；单张平面村庄地图。
- 默认第三人称越肩镜头；`C` 切换第一人称观察模式，两种模式共享同一控制和世界状态。
- 五个固定区域：主角家、院落、村中主路、晒谷场/仓房、南侧村口。
- 居民提供躲藏姿态和线索；一个追击型异变体具有巡游、警觉、追逐和失去目标状态。
- 互动：调查收音机、拾取手电、听取居民提示、开启村口铁门。
- 失败后从当前检查点重试；到达村口触发章节完成。

## 非范围

- 不做联网、开放世界、库存/成长系统、复杂战斗、多武器或多种敌人。
- 不复制任何受保护游戏的角色、场景、音频、名称或叙事。
- 第一版不包含垂直攀爬或多层玩法；建筑二层、屋顶和树冠只作不可通行的视觉装饰。

## 体验与叙事

开场由收音机杂音、熄灯和远处犬吠建立异样。院落里的邻居提示玩家避开祠堂方向；主路上熟悉村民异变，推动目标从调查转为逃离。晒谷场提供手电和出口信息；村口的铁门开启会引发追逐，穿过出口即结束。

## 空间与数据

所有玩法数据以稳定 ID 的关卡定义保存，视觉装饰、碰撞、导航和遭遇区相互独立：

- `zones`：叙事触发、检查点、出口、避险区。
- `colliders`：地面、房屋墙体、栅栏和封路物。
- `nav`：异变体巡游与追逐的平面路径节点。
- `anchors`：主角、居民、异变体、收音机、手电、铁门的稳定位置。
- `lights`：天空环境光、屋内灯、手电；每盏局部灯必须关联可见发光源。

## 角色与资产

第一版使用原创风格化拟人角色：主角、躲藏居民、异变村民均由可区分的头部、躯干、四肢和服装色块组成。以后替换为有明确许可的绑定骨骼 glTF 人物；角色 ID、碰撞和动画状态不得依赖网格细节。

## 相机与输入

- 第三人称相机平滑跟随角色右后方，保持玩家、当前威胁和前进目标可见。
- 第一人称相机与角色头部锚点同步，不改变移动或交互距离。
- 墙体遮挡时相机拉近，不能让玩家模型被遮住。
- `WASD` 移动、鼠标转向、`Shift` 跑、`E` 互动、`C` 切换视角、`R` 从失败状态重试。

## 验收标准

1. 从主角家走到村口可完成整条路线，不会穿墙或卡住。
2. 每个区域有可见地标和明确下一目标；触发顺序稳定。
3. 居民、异变体和交互物都在第三人称与第一人称中可读。
4. 异变体发现玩家后追逐；躲进指定避险区后失去目标；接触玩家进入失败状态。
5. 村口只有在完成手电和居民提示事件后可开启；出口触发完成画面。
6. `npm run build` 与浏览器试玩验证通过，固定起点截图无控制台错误。
