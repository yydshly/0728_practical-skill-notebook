# 《雾村：逃离》README 真实发布整理设计

**日期：** 2026-07-30

**状态：** 已获用户确认，等待书面设计审阅

**适用范围：** 仓库根 `README.md`、`rural-mutation-escape/` 的说明与来源文档、根目录演示素材和对应文档测试

## 1. 目标

本轮把已经合并到 `main` 的《雾村：逃离》整理成一个在远端仓库中可发现、可观看、可运行、可验证，同时不超过当前代码能力的研究项目。

交付结果应让第一次打开仓库的人从两层 README 中准确理解：

1. 这是默认第三人称、可切换第一人称的桌面浏览器逃生序章原型，不是完整商业游戏；
2. 当前可完成“收音机 → 邻居 → 手电 → 南门出口触发区”的四步线性路线；
3. 当前具备程序化村庄、静态世界碰撞、距离追逐、任务引导和原创动态音乐；
4. 失败、检查点、攻击/捕获、完整感知 AI、动态开门和完成后停机仍未实现；
5. 项目如何参考 `mshumer/Claude-of-Duty` 的工程方法，同时保持玩法、代码、场景与资产边界独立；
6. 如何在本地运行、测试和查看当前真实效果。

## 6. 项目 README 真实口径

### 6.1 首屏与演示

- 首句改为“默认第三人称、可切换第一人称”的桌面浏览器序章原型；
- 在状态说明后嵌入与根 README 共用的三张演示图；
- 明确当前完成条件是取得手电后进入南门中心半径 4.5 的出口触发区；
- 说明完成后主循环与追逐仍会继续，当前没有常驻结算层或停机。

### 6.2 控制

鼠标说明必须与运行代码一致：

> 左键点击游戏画面请求指针锁定；锁定成功后移动鼠标即可环顾，`Esc` 释放。若锁定失败，则按住左键拖动环顾。

不得继续写“只移动鼠标不会旋转”这一不分状态的结论。

### 6.3 碰撞与相机

说明区分两套机制：

- 玩家和追逐者分别使用共享静态 world collider 的 box/circle 滑动求解；
- 第三人称镜头对 `buildStructure()` 暴露的可见建筑遮挡 mesh 做 raycast 收缩；
- 玩家与追逐者之间没有通用实体互撞、推挤或伤害处理；
- 南门景物没有动态 gate collider。

不得声称镜头读取当前未接入运行路径的 `blocksCamera` 标记。

### 6.4 追逐与音频

- 追逐者描述为距离阈值状态机；
- `lost` 是回到巡逻前的短暂过渡；
- `threaten` 是近距停步、朝向和约 2.2–2.4 米间距保持，不造成攻击或捕获；
- 音频说明包含 `visibilitychange` 串行协调、BFCache 持久页面的暂停/恢复，以及非持久 `pagehide` 的终止清理；
- 静态截图不能证明声音，README 通过已提交 OGG/MP3、WAV 母带、生成脚本和 manifest 说明音频证据。
