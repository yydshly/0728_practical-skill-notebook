# 《雾屿灯塔》电影式滚动微型网站设计规格

日期：2026-07-28  
项目目录：`isle-of-quiet-signals`  
项目英文名：`Isle of Quiet Signals`

## 1. 项目目标

构建一个达到生产质量的单页电影式微型网站。网站以“雾屿灯塔”为虚构目的地，通过同一海岸场景中的 2.5D 分层运动，讲述守灯人、海上信号与岛屿航线的故事。

体验不采用多个独立全屏区块，也不使用预录视频。纵向滚动控制一个确定性的归一化时间轴，镜头像在统一世界中缓慢推进。最终状态进入可操作的横向“航线档案”。

目标受众是偏好编辑式视觉、旅行叙事、摄影与沉浸式网页体验的中文用户。页面以中文为主，英文仅作品牌名称、章节编号和少量方向性标签。

## 2. 核心信息

主标题：`雾屿灯塔`  
英文标识：`ISLE OF QUIET SIGNALS`  
核心信息：`有些光，不为抵达，只为让远方知道方向仍在。`

网站不是传统旅游宣传页，而是一封写给“仍在寻找方向的人”的海上视觉书信。

## 3. 艺术方向

### 3.1 主视觉

首屏从近岸礁石之间望向远处灯塔。左、右前景形成天然暗框，灯塔暖光是画面唯一明确高亮。海面、中远景岛体和低空薄雾保持统一的暮蓝色级。

镜头运动过程中：

- 天空与远岛仅有极轻的缩放和反向视差。
- 海面与中景岛体提供中等幅度推进。
- 灯塔主体保持稳定视觉锚点，避免漂移。
- 左右前景礁石承担最大位移，形成“入口打开”的动作。
- 薄雾、亮度和低强度模糊配合叙事焦点切换。

### 3.2 色彩与字体

设计变量至少包含：

- 主文字：旧纸白。
- 辅助文字：低饱和雾灰。
- 场景背景：深暮蓝。
- 场景染色：灰青。
- 强调色：灯塔琥珀光。
- 纸张色：微暖象牙白。
- 圆角：小到中等，避免通用大圆角卡片感。
- 阴影：低扩散、深色、克制。
- 字号：使用 `clamp()` 建立流式比例。

标题使用精致的展示型衬线字体；界面与正文使用高可读无衬线字体。首选本地或系统回退字体，避免为了装饰加载多套字重。

### 3.3 视觉约束

- 不使用玻璃拟态、霓虹或大面积装饰性渐变。
- 不将文案烘焙进图片。
- 颗粒、暗角和染色由 CSS 或轻量纹理实现。
- 模糊只用于短暂焦点转移，场景最终恢复清晰。
- 所有分层素材共享同一摄影机视角、地平线、光线和主宽高比。

## 4. 内容与叙事

### 4.1 开场

眉题：`北纬 31° · 雾季航线`  
标题：`雾屿灯塔`  
正文：`有些光，不为抵达，只为让远方知道方向仍在。`  
滚动提示：`向雾中前行`

### 4.2 叙事面板 A

章节：`01 / 守灯的人`  
标题：`每一次点亮，都是一次回答。`  
正文：`日落之后，守灯人沿一百二十七级石阶上行。没有掌声，也没有观众；只有海面在远处接住那束光。`  
事实：`自 1912 年起，每晚亮起。`

### 4.3 叙事面板 B

章节：`02 / 雾中的信号`  
标题：`看不见岸时，方向仍然存在。`  
正文：`浓雾会藏起岛屿，却藏不住光的节奏。三次短闪，一次长明，是这里写给夜航者的名字。`  
事实：`可见距离 18 海里。`

### 4.4 最终航线档案

标题：`沿着光，认识这座岛。`  
说明：`四条短途航线，从潮汐、回声、日常与风开始。`

四个档案：

1. `潮汐花园`：退潮时显露的浅水石池与海藻带。
2. `回声湾`：海蚀洞让浪声晚半拍返回。
3. `守灯人居所`：保存工具、日志与长年盐蚀的木窗。
4. `北侧风径`：沿草坡抵达岛屿最高的观景点。

卡片不伪装成外部链接。用户通过按钮、拖拽、触摸和键盘切换当前档案；当前项可展开一段补充说明，但不离开页面。

## 5. 体验架构

页面由一个长滚动容器和一个粘性全屏舞台组成：

```text
main
  section.cinematic-scroll
    div.cinematic-stage
      header.site-header
      div.world
        background-layer
        distant-island-layer
        sea-and-midground-layer
        lighthouse-layer
        foreground-left-layer
        foreground-right-layer
        mist-and-grade-layer
      article.intro-copy
      article.narrative-panel-a
      article.narrative-panel-b
      section.route-archive
```

桌面端滚动长度目标约为 4400 CSS 像素；平板与手机根据视口高度缩短行程，避免滚动疲劳。舞台使用 `position: sticky`、`top: 0`、`min-height: 100svh`，并提供 `100vh` 降级。

层级约定：

- `0–9`：场景图层。
- `10–19`：染色、雾、暗角与电影框景。
- `20–29`：叙事文案与航线档案。
- `30–39`：页头、进度与控制器。
- `40+`：必要的展开说明或加载状态。

## 6. 时间轴

所有状态由局部滚动进度 `p ∈ [0, 1]` 唯一决定，正向和反向滚动结果完全一致。

| 进度 | 场景与内容 |
| --- | --- |
| `0.00–0.03` | 完整主视觉停留 |
| `0.03–0.18` | 开场标题与文字轻微上移并退出 |
| `0.15–0.25` | 左右礁石分离，镜头推进 |
| `0.25–0.35` | 面板 A 进入并停留 |
| `0.35–0.44` | 面板 A 与前景继续退出 |
| `0.44–0.48` | 完整海岸全景停留 |
| `0.48–0.58` | 面板 B 进入，背景轻微染色和软化 |
| `0.58–0.69` | 面板 B 停留 |
| `0.69–0.76` | 面板 B 退出，世界重新清晰 |
| `0.75–0.96` | 航线档案横向进入 |
| `0.91–1.00` | 控制器出现，最终状态稳定 |

页头导航提供“灯塔”“信号”“航线”三个真实锚点。点击后换算到相应 `p` 值对应的容器滚动位置；减少动态效果模式下直接跳转或使用系统允许的平滑方式。

## 7. 分层素材计划

先制作统一构图的 16:9 高分辨率母场景，再制作或提取以下网页图层：

| 编号 | 图层 | 透明度 | 锚点 | 景深 |
| --- | --- | --- | --- | --- |
| `00` | 暮蓝天空与远海底图 | 不透明 | 中心/底部 | 最远 |
| `10` | 远岛与地平线 | 顶部透明 | 地平线 | 远景 |
| `20` | 海面与中景岛体 | 部分透明 | 底部中心 | 中景 |
| `30` | 灯塔主体与近岸建筑 | 透明 | 底部中心 | 主体 |
| `40` | 左侧近景礁石 | 透明 | 左下 | 前景 |
| `41` | 右侧近景礁石 | 透明 | 右下 | 前景 |
| `50` | 可选洞口或草叶边缘框景 | 透明 | 画布边缘 | 最近 |

所有移动图层在可见画布外保留足够出血，避免缩放或视差暴露空白边缘。最终记录实际像素尺寸、可见内容边界和优化文件大小。

卡片可使用四张同色级的局部场景图。它们在时间轴后段懒加载。原始母版和网页输出分目录保存，网页不直接传输 4K 母版。

## 8. 技术实现

使用原生 HTML、CSS 和 JavaScript，不引入 GSAP、Lenis、Three.js 或前端框架。Vite 仅作为本地开发服务器和生产构建工具，不加入任何运行时动画依赖。

JavaScript 按职责分离：

- `scene-config`：时间段、文案、图层幅度和锚点配置。
- `timeline`：`clamp()`、`lerp()`、`smoothstep()`、`rangeProgress()`、`segmentInOut()`。
- `stage`：测量、滚动目标、播放头平滑、指针平滑和 CSS 变量写入。
- `route-archive`：卡片状态、按钮、拖拽、触摸、键盘和播报。
- `assets`：关键资源解码屏障、懒加载和失败降级。

滚动、缩放和指针事件只请求下一帧。稳定几何数据在初始化或尺寸变化时缓存。播放头和指针状态收敛后停止动画帧；舞台不可见时暂停更新。主要动画只修改 `transform`、`opacity` 和少量 CSS 自定义属性。

## 9. 响应式策略

目标视口：

- `1440 × 900`
- `1280 × 720`
- `1024 × 768`
- `768 × 1024`
- `390 × 844`

桌面端保留完整镜头幅度和有限指针视差。平板减小前景位移。粗略指针与手机禁用指针视差，缩短滚动行程，重新设定主体 `object-position`，收窄文案宽度，并保证航线卡片可触摸滑动。

页面不产生横向滚动条。安全区域内边距应用于页头和底部控制器。200% 放大时，叙事内容允许进入自然文档流或重新排布，不裁掉正文和控件。

## 10. 无障碍与减少动态效果

- 使用语义化 `main`、`section`、`article`、`nav`、标题、列表和按钮。
- 装饰性场景图使用空替代文本；灯塔主视觉提供有效描述。
- 所有按钮和档案项具备可见焦点状态。
- 卡片支持左右方向键、Home 和 End。
- 状态区域只在用户主动切换后播报当前档案，避免滚动时频繁提示。
- 页面不锁死原生滚动。

`prefers-reduced-motion: reduce` 模式不运行惯性播放头、指针视差、激进缩放、模糊或大幅横移。它显示静态主视觉，再以普通文档流排列两段叙事与航线档案；信息和交互全部保留。

## 11. 加载、性能与降级

- 仅预加载首屏关键图层和必要字体。
- 关键图层通过 `image.decode()` 或等效逻辑完成后统一显现。
- 后段档案图片使用懒加载。
- 大型不透明图优先使用 AVIF/WebP；高质量 Alpha 层根据兼容性使用 WebP 或 PNG。
- 所有图像声明固有宽高或宽高比，避免布局偏移。
- 低性能环境减少模糊和滤镜，使用染色层与透明度替代。
- 单个图片加载失败时显示同色级占位层，文字、导航和档案交互仍可使用。
- 控制台保持无错误，舞台离开视口后不持续运行。

## 12. 验收与测试

在 `p = 0.00、0.18、0.27、0.44、0.58、0.74、0.90、1.00` 检查：

- 无透明空洞或画布边缘。
- 图层顺序稳定。
- 无文字碰撞或不可读叠加。
- 无突变、拉伸或关键主体严重裁切。
- 无明显加载闪烁。
- 无横向溢出。

同时验证：

- 正向和反向滚动的确定性。
- 五种目标视口。
- 鼠标、触摸模拟与键盘操作。
- 页头时间轴跳转。
- 200% 浏览器放大。
- `prefers-reduced-motion`。
- 图片加载失败降级。
- 控制台错误。
- 首屏与后段资源体积。
- 普通笔记本与现代手机上的可接受帧稳定性。

## 14. 完成定义

只有在以下条件全部成立时才算完成：

- 首屏是一幅完整、精致的编辑式构图。
- 滚动像摄像机在同一世界中移动。
- 两个叙事节点都有明确的进入、停留和退出。
- 反向滚动可干净反转全部视觉状态。
- 最终档案支持按钮、拖拽、触摸和键盘操作。
- 手机和减少动态效果版本保留全部内容。
- 素材加载无明显跳变。
- 所有导航和按钮均有效。
- 控制台无报错。
- 代码、素材清单和时间轴文档足以让其他开发者替换素材或调整节奏。
