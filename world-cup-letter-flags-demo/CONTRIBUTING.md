# Contributing

Thanks for helping improve Final Four — Typographic Flags.

## Development

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm ci`.
3. Run the app with `npm run dev`.
4. Verify the production build with `npm run build`.

Keep changes scoped and preserve the reduced-motion path, keyboard navigation and responsive layout.

## Assets and data

- Only submit assets you created or have permission to redistribute.
- Do not commit broadcast commentary, match footage, federation marks, player photography or other copyrighted media without an explicit compatible license.
- Document roster changes and factual corrections with a primary source.
- Optimize raster assets before committing them and avoid unnecessary duplicates.

## Pull requests

Explain what changed, why it changed and how you verified it. Include screenshots or a short recording for visual or motion changes.
