# Commentary clip slots

FIFA's official YouTube highlights were tested, but the rights holder disables playback in third-party embedded players. The application therefore looks for local audio files in this directory.

The expected filenames are:

- `spain-opener-vs-belgium.mp3` — Spain's opening goal against Belgium
- `spain-qf-merino-88.mp3` — Mikel Merino's 88th-minute winner vs Belgium
- `england-qf-bellingham-93.mp3` — Jude Bellingham's extra-time winner vs Norway
- `england-equalizer-vs-norway.mp3` — Jude Bellingham's equaliser vs Norway
- `england-semi-final-whistle.mp3` — England advance to the final four
- `france-qf-mbappe-60.mp3` — Kylian Mbappé's opener vs Morocco
- `france-second-goal-vs-morocco.mp3` — France double their lead against Morocco
- `france-semi-final-whistle.mp3` — France advance to the semi-finals
- `argentina-qf-alvarez-112.mp3` — Julián Álvarez's extra-time winner vs Switzerland
- `argentina-opener-vs-switzerland.mp3` — Argentina's opening breakthrough vs Switzerland
- `argentina-semi-final-clincher.mp3` — the clincher and final-four commentary

There is deliberately no generated crowd noise and no browser speech fallback. Audio files are ignored by Git so unlicensed broadcast recordings are not accidentally published.

Only add and distribute clips when you own the recording or have explicit permission for web and repository distribution. Keep each excerpt short, normalize it to roughly -16 LUFS, add a 20-40 ms fade at both ends, and document the source and license below.
