# Fungarium Product Showcase

A standalone Vite and React product-showcase application.

## Requirements

Node.js 22 or newer.

## Commands

- `npm run dev` starts the development server.
- `npm test` runs unit tests.
- `npm run build` writes a production build to `dist/`.
- `npm run test:browser` runs Playwright tests.

## Provenance and assets

This project records the upstream `nesdesignco/fungarium` repository only as
source-code provenance. See [UPSTREAM.md](./UPSTREAM.md) for the pinned source
revision and asset boundary.
